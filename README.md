# Abartılı Miyav Çevirici

## Dünyanın En Devrimsel Teknolojisi

Bu repository, insanlık tarihinin en önemli icadını barındırmaktadır: **Abartılı Miyav Çevirici**.

### Ne Yapar?

Herhangi bir metni, bilimsel olarak doğrulanmış ve kediler tarafından onaylanmış miyav diline çevirir. 

- "Merhaba dünya" → "miyav MIYAV miiiyav"
- Her şey miyav olur.
- Çıktılar rastgele ve komiktir.
- Gerçekten çalışır.

### Neden Önemli?

1. Kedilerle iletişim kurmanı sağlar (belki).
2. Geleceğin resmi dili miyav olacaktır.
3. Bilim adamları bu teknoloji karşısında şaşkındır.
4. Dünya barışına katkı sağlar (kesinlikle).

### Kurulum ve Kullanım

```bash
python miyav_cevirici.py
```

İstediğin metni yaz, miyav dilinde al. Bu kadar basit. Bu kadar devrimsel.

### Uyarı

Bu programı kullananlar miyav dilini konuşmaya başlayabilir. Sorumluluk kabul etmiyoruz.
